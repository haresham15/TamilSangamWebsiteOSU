# Games Page v1.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the reference-calibrated `/games` route ("The Sangam Arcade & Beach Blast Sequence") with all 15 defect fixes (D-01 to D-15), featuring a locked lens-shifted 3D hero that passes numeric parity and lens registration gates, and a monthly Tamil games hub (Sollu & Thodarpu).

**Architecture:** Single persistent Drei `<View>` mounted inside `GlobalCanvas` driven by `MotionProvider`. Background scene renders the 37m coastal compound; foreground renders 1:1 eyeglasses & hand rig at 0.36m. `LayeredFocusCompositor` manages dual off-screen targets and separable blur without depth halos or transmission passes. Sheet handoff glides to NYT-style Sangam Arcade with local storage schema `osu_ts_arcade_v1`.

**Tech Stack:** Next.js 16 (App Router), React 19, Three.js (r186), React Three Fiber (v9), Drei, GSAP 3 (Flip & ScrollTrigger), Lenis, Vitest, Tailwind CSS v4, Lucide React.

**Spec:** `PRD — Games Page v1.1 · The Sangam Arcade & Beach Blast Sequence`

## Global Constraints

- Package manager: strictly `npm` only (`package-lock.json` invariant).
- Single persistent canvas: Mount hero inside existing `GlobalCanvas` via Drei `<View>`. No secondary canvas or RAF loops.
- Rights & reputation: Never ship reference stills into `/public`; never render film logos, watermarks, or studio names; use codename `"Beach Blast"`.
- Token colors: Tinted OKLCH/hex semantic tokens in Chola palette (`#FAF6F0`, `#F2EAE0`, `#161210`, `#D4AF37`, `#B24A25` Tier 3 AA contrast >= 4.5:1).
- Tamil typography: `lang="ta"` on Tamil elements, 0 positive letter-spacing, line-height >= 1.5, grapheme clusters split with `Intl.Segmenter('ta', { granularity: 'grapheme' })`.
- Build gates: `scripts/verify-games-data.mjs`, `scripts/verify-frame-parity.mjs`, and `scripts/verify-lens-registration.mjs` must run and exit 0.

## Review Focus

1. **Lens Registration at extreme aspect ratios:** At 3.0 ultra-wide or 9:16 mobile portrait, fireballs must not shift out of the eyeglass apertures. Fixed camera-space metres (C-1) and dedicated portrait solver (C-2) pin this.
2. **Tamil grapheme normalization:** Compound ligatures like கொ and symbols with decomposed vowels must not split into separate tiles. `normalize("NFC")` + `Intl.Segmenter` handles this.
3. **Wordle duplicate-letter evaluation:** Guessing two identical letters when answer has one must color only the first misplaced instance yellow, never both. Two-pass algorithm pins this.
4. **Foreground blur alpha fringes:** Defocused eyeglass rims must have soft translucent alpha edges over the sharp blast without dark halo artifacts. Premultiplied alpha blur in `LayeredFocusCompositor` pins this.
5. **No layout shift or scroll trap:** Skipping to `#arcade` or cold loading with `#arcade` hash must immediately position the page at the arcade sheet without running unnecessary 3D loops.
